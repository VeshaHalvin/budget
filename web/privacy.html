Privacy Policy — Daily Budget

Last updated: November 10, 2026

Daily Budget is a personal tool used only by its owner to track daily spending. It is not offered to the public.

What data it accesses

With the owner's permission, the app reads (read-only) credit card transaction notification emails in the owner's Gmail account. It extracts only the merchant name, amount, currency and time of each transaction.

How data is used and stored

Extracted transactions are stored in the owner's private database and used only to calculate the owner's daily budget and send the owner notifications. Email contents are not stored. No data is sold, shared with third parties, or used for advertising.

Google user data

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
